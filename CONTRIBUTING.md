# Contributing to Health Without Borders Frontend

Thank you for contributing. This repository follows the same governance model used by the backend project.

## 1) Before Coding

- Open or discuss an issue first for non-trivial changes.
- Align with UI/UX decisions in Figma before implementing new screens.

## 2) Local Setup

Follow `docs/development/setup.md` for environment setup.

## 3) PR and QA Workflow

Follow `docs/development/qa-plan.md` and ensure:

1. `~/.pub-cache/bin/fvm flutter analyze` passes
2. `~/.pub-cache/bin/fvm flutter test` passes
3. PR targets `develop`
4. PR uses `.github/PULL_REQUEST_TEMPLATE.md`

## 4) Code of Conduct

All participants must follow `CODE_OF_CONDUCT.md`.
